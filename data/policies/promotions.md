# Promotions

## 1. Promo codes

New customers get 40% off the food subtotal of their first order, up to $5.00, with the code in the welcome email. Other promo codes are sent by email or shown in the app. Only one promo code can be used per order, and a code cannot be added after the order is placed.

## 2. Referral vouchers

When a customer invites a friend and the friend completes a first order, both receive a $3.00 voucher. Referral vouchers are valid for 30 days and can be used on any order over $10.00.

## 3. Using vouchers

Vouchers in a customer's account are applied at checkout, the oldest first. A voucher cannot be exchanged for cash. A voucher can be combined with a promo code.
